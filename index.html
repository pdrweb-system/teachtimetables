การเชื่อมต่อ API

URL ของ Apps Script (Web app) ที่หน้าเว็บนี้เรียกใช้เป็นฐานข้อมูล — ขอจากผู้ดูแลระบบ

วิธีใช้

  1. เลือกวัน แล้วกด + เพิ่มครู ที่ไม่อยู่
  2. กด ⚡ จัดอัตโนมัติ หรือแตะเลือกครูสอนแทนเองทีละคาบ แล้วกด 💾 บันทึก
  3. ส่งคำว่า แจ้งตารางสอนแทน ในกลุ่มไลน์ บอทจะตอบเป็นการ์ดตารางสอนแทนของวันนี้

ข้อมูลครูและตารางสอน

ถ้าผู้ดูแลแก้รายชื่อครูหรือตารางสอน กดปุ่มนี้เพื่อดึงข้อมูลล่าสุด

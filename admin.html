การเชื่อมต่อ API

วาง URL ของ Apps Script (ลงท้ายด้วย /exec)

ตั้งรหัสผู้ดูแล

ยังไม่เคยตั้งรหัส — ตั้งเดี๋ยวนี้ ก่อนแจก URL ให้ใคร (อย่างน้อย 6 ตัวอักษร) รหัสนี้ใช้เข้าหน้านี้เท่านั้น ครูไม่ต้องใช้

เข้าสู่ระบบผู้ดูแล

ลืมรหัส: ใน Apps Script เปิด “การตั้งค่าโปรเจกต์ → คุณสมบัติของสคริปต์” แล้วลบ ADMIN_HASH และ ADMIN_SALT จากนั้นเปิดหน้านี้ใหม่เพื่อตั้งรหัสใหม่

ข้อมูลครูและตารางสอน

แก้รายชื่อครู คาบเรียน ตารางสอน และข้อความตั้งค่า (ชื่อโรงเรียน ผู้จัด ข้อความท้ายประกาศ) ได้ใน Google Sheet แล้วให้ครูกด “โหลดข้อมูลใหม่” ในหน้าจัดสอนแทน

นำเข้าตารางสอนจาก PDF

เลือกไฟล์ PDF ตารางสอนที่ เลือกข้อความได้ (เช่น ส่งออกจาก Word/Excel — PDF ที่สแกนจากกระดาษอ่านไม่ได้) ระบบอ่านไฟล์ในเครื่องนี้ แล้วแสดงตัวอย่างให้ตรวจก่อนบันทึกลงชีต “ตารางสอน”
